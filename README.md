# Jeonghoon Oh | Text Mining Portfolio

Personal academic portfolio showcasing Text Mining coursework at Rutgers University.

[Visit the website](https://rutjo23.github.io/?v=b00ce3c)

## Projects

- **10-K Sentiment Analysis (Assignments 3–4)** — Measure positive, negative, and litigious language in financial filings.
- **Readability & Forward-Looking Language (Assignment 5)** — Analyze sentence complexity, Gunning FOG, and future-oriented statements.
- **MD&A Extraction & Disclosure Analytics (Assignment 6)** — Extract Item 7 and compare text features across full filings and MD&A.
- **Remarks Lab (Assignments 7–8)** — Classify prepared remarks and management Q&A answers using Naive Bayes. [Try the demo](https://rutjo23.github.io/projects/remarks-lab.html).

## Technologies

HTML, CSS, JavaScript, Python, pandas, BeautifulSoup, and NLTK.
